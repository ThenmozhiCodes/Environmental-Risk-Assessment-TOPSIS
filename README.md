# Environmental-Risk-Assessment-TOPSIS
🌱 Project Showcase: Environmental Risk Assessment and Decision Support System Using TOPSIS

I’m happy to share that I have successfully developed and deployed my MSc Computer Science project, “Decision Support for Environmental Risk Management Using TOPSIS.”

**About the Project**

Environmental factors such as air pollution, rainfall variations, soil quality, and agricultural conditions can significantly affect the environment and human activities. This project aims to assess environmental risks using the **TOPSIS (Technique for Order Preference by Similarity to Ideal Solution)** method and support informed decision-making.

🔹 **Key Features**

✅ **Environmental Risk Assessment:** Evaluates environmental parameters to calculate risk scores.

✅ **Air Pollution Analysis:** Assesses air quality using PM2.5, PM10, NO₂, and SO₂.

✅ **Rainfall Risk Analysis:** Considers rainfall, minimum and maximum temperature, and humidity.

✅ **Soil Quality Assessment:** Evaluates soil properties such as pH, nitrogen, phosphorus, and potassium (NPK).

✅ **Crop Area Analysis:** Considers crop area, cultivated area, production, and yield.

✅ **Location-Based Assessment:** Supports district- and place-based analysis for selected locations in Tamil Nadu.

✅ **TOPSIS-Based Decision Support:** Uses a multi-criteria decision-making approach to calculate scores and classify risks as Low, Moderate, or High.

✅ **Interactive Visualizations:** Includes maps and charts to present environmental assessment results.

✅ **User Authentication:** Provides registration, login, and password recovery functionality.

🔹 **Technologies Used**

💻 Frontend: HTML, CSS, JavaScript

📊 Data Processing: Pandas, NumPy  
🗄️ Database: SQLite
